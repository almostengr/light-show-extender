# Lights Naming Pattern

## Compact Christmas Light Labeling Code

**Format:**  
`[Bulb Count][Location][Two-Digit Year]`

## Example Code Structure

- **95FR23**  
  - `95` = Number of bulbs  
  - `FR` = Front Roof  
  - `23` = Two-digit year (2023)

## Location Abbreviation Suggestions

- `FR` – Front Roof  
- `WL` – Window Left  
- `WR` – Window Right  
- `GD` – Garage Door  
- `TP` – Tree Porch  
- `BK` – Backyard  

## Label Examples

| Code    | Meaning                                  |
|---------|------------------------------------------|
| `95FR23`  | 95 bulbs, Front Roof, started in 2023     |
| `50GD22`  | 50 bulbs, Garage Door, started in 2022    |
| `100TP21` | 100 bulbs, Tree Porch, started in 2021    |


# Letter Codes

IT - Inside Tree
PT - Popcorn Tree
MT - Mini Tree

IT1.A.60.15

IT1 - Inside Tree Circuit 1
A - First string on circuit (numbered alphabetically)
60 - number of lights on string 
15 - first year string used
